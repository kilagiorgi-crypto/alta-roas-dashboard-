# ROAS/CAC ყურადღების პანელი — გახსნა

## როგორ გავხსნა

ორჯერ დააწკაპუნეთ **`dashboard.html`**-ზე. გაიხსნება ბრაუზერში.

ინტერნეტი არ სჭირდება. დაყენება არ სჭირდება.

## როგორ გამოვიყენო

1. ჩააგდეთ XLSX ფაილი გვერდზე ან დააწკაპუნეთ და აირჩიეთ.
2. ფაილი მოწმდება. თუ შეცდომაა, ჩატვირთვა ჩერდება და ყველა შეცდომა ჩამოითვლება.
3. სუფთა ფაილზე გამოჩნდება მაჩვენებლები, გრაფიკი და ცხრილები.
4. ფილტრები და მონიშვნის წესი მაშინვე გადაითვლის ყველაფერს.
5. „CSV-ში ექსპორტი" ჩამოტვირთავს ეკრანზე ნაჩვენებ ცხრილს გამოყენებული ფილტრებით.

ახალი ფაილი სრულად ანაცვლებს წინას. ძველი მონაცემები არ რჩება.

## მონაცემები
